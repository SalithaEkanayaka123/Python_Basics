Question 1: What is a custom exception?

Answer:

A custom exception is a user-defined exception class created by extending Python’s Exception class. It is useful for representing application-specific or business-specific errors.

Question 2: Why use custom exceptions?

Answer:

Custom exceptions make error handling clearer. Instead of using generic errors everywhere, we can represent business errors such as invalid status, duplicate application, or application not found.

Question 3: What is raise?

Answer:

raise is used to throw an exception in Python.

Example:

raise ValueError("Invalid value")
Question 4: Difference between raise and except?

Answer:

raise is used to create or throw an exception. except is used to catch and handle an exception.

Question 5: Why create a base exception class?

Answer:

A base exception class allows us to group related exceptions. For example, all job application errors can extend ApplicationError, so we can catch them together.

Example:

except ApplicationError as error:
    print(error)
