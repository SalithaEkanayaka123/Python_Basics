1. What is __str__?

__str__ returns a user-friendly string representation of an object. It is used when calling print() or str().

2. What is __repr__?

__repr__ returns a developer-friendly representation of an object. It is mainly useful for debugging.

3. Difference between __str__ and __repr__?

__str__ is for users. __repr__ is for developers and debugging. If __str__ is not defined, Python may use __repr__.

4. What is __eq__?

__eq__ defines how two objects are compared using ==.

5. Why did app1 == app2 return false before using __eq__?

Because Python compares object identity by default. Even if two objects contain the same values, they are different objects in memory unless equality is customized.

6. What is __len__?

__len__ allows an object to work with the built-in len() function.

7. What is __dict__?

__dict__ stores an object’s attributes as a dictionary.
