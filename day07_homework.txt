Question 1: What is list comprehension?

Answer:

List comprehension is a concise way to create a new list from an existing iterable by applying an expression and optional condition.

Example:

even_numbers = [number for number in numbers if number % 2 == 0]
Question 2: What is the difference between sort() and sorted()?

Answer:

sort() modifies the original list. sorted() returns a new sorted list and keeps the original list unchanged.

Question 3: What is lambda?

Answer:

Lambda is an anonymous function used for small, simple operations. It is commonly used with sorted, map, and filter.

Question 4: Difference between map() and filter()?

Answer:

map() transforms each item. filter() selects items that match a condition.

Example:

numbers = [1, 2, 3]

doubled = list(map(lambda n: n * 2, numbers))
even = list(filter(lambda n: n % 2 == 0, numbers))
Question 5: When should you avoid list comprehension?

Answer:

Avoid list comprehension when the logic becomes too complex. In that case, a normal loop is more readable and maintainable.

Good:

active_users = [user for user in users if user["active"]]

Too complex:

# Hard to read if multiple nested conditions and transformations are added

Use a normal function or loop instead.
