Interview theory from today
Question 1: What is a function in Python?

Answer:

A function is a reusable block of code defined using the def keyword. It can accept parameters, perform logic, and optionally return a value.

Question 2: What is the difference between parameter and argument?

Answer:

A parameter is the variable defined in the function declaration. An argument is the actual value passed when calling the function.

Example:

def greet(name):  # name is parameter
    print(name)


greet("Salitha")  # "Salitha" is argument
Question 3: What is a default parameter?

Answer:

A default parameter provides a default value when the caller does not pass that argument.

def create_user(role="user"):
    return role
Question 4: Why are type hints useful?

Answer:

Type hints improve readability, IDE support, maintainability, and help tools detect possible type issues. They do not make Python strictly typed at runtime.

Question 5: Why should we avoid large functions?

Answer:

Large functions are difficult to read, test, debug, and maintain. Small functions with one responsibility improve code quality.

Question 6: What is the mutable default argument issue?

Answer:

If we use a mutable object like a list or dictionary as a default argument, Python can reuse the same object across multiple function calls. This can cause unexpected behavior.

Bad:

def add_item(item, items=[]):
    items.append(item)
    return items

Good:

def add_item(item, items=None):
    if items is None:
        items = []

    items.append(item)
    return items
