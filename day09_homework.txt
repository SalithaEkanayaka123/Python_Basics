1. What is @staticmethod?

@staticmethod defines a method inside a class that does not need access to instance data or class data. It is useful for utility methods.

2. What is @classmethod?

@classmethod receives the class as the first parameter using cls. It can access class variables and is commonly used as an alternative constructor.

3. What is @property?

@property allows controlled access to class attributes. It works like a getter and can be combined with a setter for validation.

4. What is a dataclass?

A dataclass is a Python class mainly used to store data. It automatically generates methods such as __init__ and __repr__.

5. What is an abstract class?

An abstract class defines a contract that child classes must implement. In Python, we use ABC and @abstractmethod.
