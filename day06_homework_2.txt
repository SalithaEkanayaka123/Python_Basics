Question 1: What is exception handling?

Answer:

Exception handling is used to handle runtime errors without crashing the program. In Python, we use try, except, and optionally finally.

Question 2: What is the difference between except Exception and specific exceptions?

Answer:

Specific exceptions like ValueError or FileNotFoundError are better because they handle known problems clearly. Catching general Exception can hide unexpected bugs.

Question 3: What is JSON?

Answer:

JSON is a lightweight data format used for exchanging data between systems. It is commonly used in REST APIs. Python provides the json module to read and write JSON data.

Question 4: What does json.dump() do?

Answer:

json.dump() writes Python data into a JSON file.

Example:

json.dump(data, file, indent=4)
Question 5: What does json.load() do?

Answer:

json.load() reads JSON data from a file and converts it into Python objects such as dictionaries or lists.

Question 6: Why use with open()?

Answer:

with open() automatically closes the file after reading or writing. It is safer and cleaner than manually opening and closing files.
