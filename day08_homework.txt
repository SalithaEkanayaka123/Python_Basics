Question 1: What is a class in Python?

Answer:

A class is a blueprint for creating objects. It defines attributes and methods that represent the behavior and state of an object.

Question 2: What is an object?

Answer:

An object is an instance of a class. It contains actual data and can use the methods defined in the class.

Question 3: What is self?

Answer:

self refers to the current object instance. It allows access to instance variables and methods inside the class.

Question 4: What is __init__?

Answer:

__init__ is a special method used to initialize object attributes when an object is created.

Question 5: Is self a keyword?

Answer:

No. self is not a reserved keyword, but it is the standard convention in Python. We should always use self for readability and consistency.

Question 6: What is inheritance?

Answer:

Inheritance allows one class to reuse or extend the behavior of another class. The child class can access parent class methods and can also override them.

Question 7: What is method overriding?

Answer:

Method overriding happens when a child class provides its own implementation of a method already defined in the parent class.

Question 8: What is super()?

Answer:

super() is used to call a method from the parent class, commonly the parent class constructor.
