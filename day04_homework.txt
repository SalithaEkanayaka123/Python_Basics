Day 4 exercises

Complete these after the mini project.

Exercise 1

name
role
experience
main_skill
target_skill

Exercise 2

Create a list of 3 job applications using dictionaries.

Each application should have:

company
role
status
location

Exercise 3

skills = ["Java", "Python", "Java", "SQL", "Python", "Docker"]

Exercise 4

Create a tuple:

valid_roles = ("Software Engineer", "Senior Software Engineer", "Tech Lead")

Print:

Valid role

or

Invalid role
Exercise 5

Create a list of applications:

applications = [
    {"company": "WSO2", "status": "applied"},
    {"company": "IFS", "status": "interview"},
    {"company": "Virtusa", "status": "applied"},
    {"company": "Hatchyard", "status": "rejected"}
]

Count how many applications are in each status.

Expected output:

applied: 2
interview: 1
rejected: 1
Exercise 6

Print:

or

IFS application not found
Exercise 7
